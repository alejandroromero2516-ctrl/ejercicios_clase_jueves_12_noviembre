# Ejercicios de clase - 12 de noviembre

Ejemplos de listas y mapas en Java y Python, hechos en la clase de Programación Orientada a Objetos.

## Organización

- `java/`: los ejemplos en Java.
- `python/`: los mismos ejemplos en Python.

Cada tema tiene su archivo en las dos carpetas: operaciones con listas, operaciones con mapas, mapas con objetos como clave, recorridos, ordenamiento y streams.

## Java

Desde la carpeta `java`, con JDK 17 o superior:

```bash
javac *.java
java JavaArrayList
```

Los demás se ejecutan igual, cambiando el nombre de la clase: `JavaHashMap`, `JavaMapaCoordenada`, `JavaRecorridos`, `JavaOrdenamiento` y `JavaStreams`.

## Python

Desde la carpeta `python`, con Python 3.10 o superior:

```bash
python ejemplo_lista.py
```

Los demás son `ejemplo_diccionario.py`, `ejemplo_mapa_coordenada.py`, `ejemplo_recorridos.py`, `ejemplo_ordenamiento.py` y `ejemplo_funcional.py`.
